# ARCHITECT CONTEXT — inventory_management — last updated 2026-06-04

## META
Custom inventory, sales, purchase management. Python 3. Odoo 16. PostgreSQL.
Entry point: __manifest__.py.

## ARCHITECTURE PATTERN
Odoo MVC framework. Model-View-Controller.
Models in models/. Views in views/. Controllers in controllers/.

## FOLDER MAP
controllers/ — HTTP endpoints. Scaffold boilerplate only.
data/ — Default and sequence XML data.
demo/ — Demo XML data.
models/ — Python ORM models and wizards.
reports/ — PDF print layouts and action reports.
security/ — Model access control list rules (ir.model.access.csv).
tests/ — Unit and integration tests.
views/ — XML view actions, menus, layouts.

## MODULES

### inventory_management
Primary module. Extends core Odoo product/stock/sale/purchase behaviors.
Depends: uom, product, stock, sale, purchase, mail, product_expiry. Used by: none.

### models
Contains master records (category, config), Odoo core extensions (product, lot, sale), wizards.
Depends: Odoo ORM. Used by: views, controllers.

## NAMING CONVENTIONS
Files: snake_case [inventory_category.py, product_views.xml]
Classes: PascalCase [InventoryCategory, AgroSaleWizard]
Fields: snake_case [uom_id, category_id, lot_ids]
Views: snake_case [product_views.xml, menus.xml]

## ERROR HANDLING CONTRACT
ORM validation errors. UserError/ValidationError thrown inside Python models.
Odoo framework catches and displays to user via web UI.

## LOGGING CONTRACT
Python logger. Odoo framework logging standard.
Uses logging.getLogger('odoo.addons.inventory_management').

## DATA FLOW
User interacts with Odoo Web client → views request actions → wizards/models trigger Python methods → Odoo ORM updates PostgreSQL → view updates.

## DEPENDENCIES — EXTERNAL
Odoo base framework — core modules (uom, product, stock, sale, purchase, mail)

## DEPENDENCIES — INTERNAL
views depend on: models, security, data.
models depend on: other models.

## TEST STRATEGY
Odoo TransactionCase tests. Wizard behavior, discount math, and stock validation tested.
Files: tests/test_[concern].py. Run via Odoo CLI test runner.

## KNOWN DEBT
None.
