# ARCHITECT CONTEXT — inventory_management — last updated 2026-07-06

## META
Custom inventory, sales, purchase management. Python 3. Odoo 16. PostgreSQL.
Entry point: __manifest__.py.

## ARCHITECTURE PATTERN
Odoo MVC framework. Model-View-Controller.
Models in models/. Views in views/. Controllers in controllers/.

## FOLDER MAP
controllers/ — HTTP endpoints. JSON-RPC dashboard endpoints. Namespace: /agro/dashboard/*.
data/ — Default and sequence XML data. agro_dashboard_cron.xml added (nightly product stats refresh).
demo/ — Demo XML data.
models/ — Python ORM models and wizards.
reports/ — PDF print layouts and action reports.
security/ — Model access control list rules (ir.model.access.csv).
static/src/js/ — OWL frontend JS components.
static/src/xml/ — OWL QWeb templates.
static/src/css/ — Dashboard CSS.
tests/ — Unit and integration tests.
views/ — XML view actions, menus, layouts.

## MODULES

### inventory_management
Primary module. Extends core Odoo product/stock/sale/purchase behaviors.
Depends: uom, product, stock, sale, purchase, mail, product_expiry. Used by: none.

### models
Contains master records (category, config), Odoo core extensions (product, lot, sale), wizards, dashboard engine, stock audit.
Depends: Odoo ORM. Used by: views, controllers.

### agro_dashboard
AbstractModel. Stateless KPI engine. @api.model methods only. Returns JSON-serializable dicts.
All dashboard KPI computation lives here. Controller dispatches to it. No business logic in controller.

### agro_stock_audit
Immutable append-only stock movement log. write()/unlink() blocked at model level. Created by wizards or manually.

### OWL Dashboard Frontend
Client action tag: agro_business_dashboard. OWL component in static/src/js/agro_dashboard.js.
Templates: static/src/xml/agro_dashboard_templates.xml. CSS: static/src/css/agro_dashboard.css.
Chart.js 4.4.0 loaded via CDN in web.assets_backend.

## ERROR HANDLING CONTRACT
ORM validation errors. UserError/ValidationError thrown inside Python models.
Odoo framework catches and displays to user via web UI.

## LOGGING CONTRACT
Python logger. Odoo framework logging standard.
Uses logging.getLogger('odoo.addons.inventory_management').

## DATA FLOW
User interacts with Odoo Web client → views request actions → wizards/models trigger Python methods → Odoo ORM updates PostgreSQL → view updates.

## DEPENDENCIES — INTERNAL
